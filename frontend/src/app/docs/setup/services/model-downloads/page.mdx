# Model downloads (Hugging Face Hub)

<ServiceFacts id="model-downloads" />

## Minimal setup

1. Pick a cache location and set `HF_HOME` (default `~/.cache/huggingface`). In
   containers, mount it as a volume so each model downloads once.
2. Install the extras for the backends you want:
   - `argus-lens[wd14]`: WD14 on CPU onnxruntime, no torch.
   - `argus-lens[torch]`: RAM++, Florence-2, BLIP-2.
   - `argus-lens[local]`: all of them.
3. For a gated model, create a read token and export `HF_TOKEN`. The Hub client
   picks it up from the environment.

Lens loads `florence-community/Florence-2-base` by default, which needs no
remote code. The original `microsoft/Florence-2-base` runs only with
`HF_TRUST_REMOTE_CODE=1`. See
[trust_remote_code and Florence-2](https://github.com/smk762/argus-lens/blob/dev/README.md#trust_remote_code-and-florence-2)
before turning that on.
