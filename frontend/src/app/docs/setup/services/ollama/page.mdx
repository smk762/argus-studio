# Ollama

<ServiceFacts id="ollama" />

## Minimal setup

1. Install Ollama (native or Docker) and pull the models you'll use. For example,
   lens's refine default and a vision model for captions:

   ```bash
   ollama pull qwen3:8b
   ollama pull qwen3-vl:8b
   ```

2. Ollama listens on `127.0.0.1:11434` by default. For containers or other
   machines to reach it, set `OLLAMA_HOST=0.0.0.0` on the Ollama side, and only
   on a trusted network: Ollama has no authentication.
3. Point the clients at it:
   - **lens** uses the OpenAI-compatible path, with `/v1`:
     `ARGUS_OPENAI_COMPAT_BASE_URL=http://<GPU_HOST>:11434/v1` and
     `ARGUS_OPENAI_COMPAT_MODEL=qwen3-vl:8b`.
     From inside a container on the same machine, use
     `http://host.docker.internal:11434/v1`.
   - **darkroom** uses Ollama's native API, with no `/v1`:
     `ARGUS_DARKROOM_OLLAMA_URL=http://<GPU_HOST>:11434` and a model in
     `ARGUS_DARKROOM_OLLAMA_MODEL`. Both must be set for `--expand` to work.

Studio's `lens` profile runs its own Ollama, and a one-shot `ollama-pull`
fetches the refine model, so you need neither step for that profile.
