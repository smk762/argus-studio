# EraX-NSFW

<ServiceFacts id="erax-nsfw" />

## Minimal setup

1. Serve the EraX-NSFW YOLO weights behind a small HTTP sidecar that speaks
   NudeNet's `POST /infer` (multipart in, `{"prediction": [...], "success": true}`
   out). Curator expects EraX's own classes: `anus`, `make_love`, `nipple`,
   `penis` and `vagina`.
2. Set `ARGUS_CURATOR_ERAX_URL` to its origin. Empty or unset turns it off.

`--no-nsfw` turns off both NudeNet and EraX. When EraX fills a gap, the result
records `erax_filled: true` (and `nudenet_failed: true` if NudeNet had failed).
