## Minimal setup

Each model is converted to ONNX once, into curator's model directory:

```bash
pip install 'argus-curator[places365-convert,garments-convert]'
argus-curator places365-convert --arch resnet18   # or resnet50
argus-curator garments-convert
```

To keep the files elsewhere, set `ARGUS_CURATOR_PLACES365_MODEL` and
`ARGUS_CURATOR_GARMENTS_MODEL` to their paths. The converter extras are needed
only for the conversion, not at scan time.
