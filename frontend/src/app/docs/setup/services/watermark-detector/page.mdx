# Watermark detector

<ServiceFacts id="watermark-detector" />

## Minimal setup

1. Serve a YOLO watermark model, either the YOLO11x from the JoyCaption space or
   the lighter YOLOv8 one, behind a sidecar that speaks NudeNet's `POST /infer`.
2. Set `ARGUS_CURATOR_WATERMARK_URL` to its origin. The `_TIMEOUT` and
   `_WORKERS` variables tune it.

See [finding watermarks](https://github.com/smk762/argus-curator/blob/dev/docs/crops.md#finding-watermarks)
for what curator does with the boxes.
