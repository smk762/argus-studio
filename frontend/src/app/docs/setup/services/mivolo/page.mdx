# MiVOLO v2 (age estimate)

<ServiceFacts id="mivolo" />

## Minimal setup

1. Convert the model once. This fetches the pinned `iitolstykh/mivolo_v2` from
   Hugging Face and writes `mivolo_v2_d1_384.onnx` into curator's model directory:

   ```bash
   pip install 'argus-curator[mivolo-convert]'
   argus-curator mivolo-convert
   ```

2. To keep the model somewhere else, point `ARGUS_CURATOR_MIVOLO_MODEL` at the file.
3. For darkroom, either:
   - point `ARGUS_DARKROOM_AGE_URL` at a curator's `POST /faces?body=true`, or
   - install darkroom's `[age]` extra and give it the same ONNX file.

An age check that can't run never deletes an image on its own. See
[Moderation](/docs/setup/moderation#the-age-estimate-feeds-the-under-18-rules)
for how the estimate is used.
