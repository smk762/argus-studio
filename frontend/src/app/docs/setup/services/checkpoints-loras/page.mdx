# Checkpoints and LoRAs

<ServiceFacts id="checkpoints-loras" />

## Minimal setup

1. Keep checkpoints and LoRAs in ComfyUI's layout: `models/checkpoints/`,
   `models/loras/` and so on. If ComfyUI also reads folders listed in
   `extra_model_paths.yaml`, mount the folder it actually lists.
2. Mount the tree read-only into each service, at the container path it expects:
   - **darkroom**: host path in `MODELS_ROOT`, at `/models`;
   - **proof**: `PROOF_MODELS_DIR`, for example `/data/models:/data/models-extra`;
   - **atlas**: `ATLAS_MODELS_DIR` (default `/data/models`), used only to pin SHA256s.
3. Name a model the way ComfyUI loads it, as a path relative to its folder.

To make trained LoRAs show up, point forge's output at the same `loras/`
folder (see [ComfyUI](/docs/setup/services/comfyui)). Atlas's
`scripts/fetch_civitai_lora.py` reads `CIVITAI_TOKEN` to download the cartography LoRA.
