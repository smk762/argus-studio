# Setup and services

Most Argus packages are **clients of services they don't ship**. ComfyUI
renders, Ollama or a vLLM server writes prose, NudeNet and SingGuard judge,
model weights come from Hugging Face, and much of it needs a GPU host. Each
package's README covers its own part. These pages cover the shared services
once, so that running darkroom, say, doesn't mean reading four READMEs.

Every service page lists:

- **who uses it**: each package, and the exact env var or flag it reads;
- **the minimal setup**, written out where the suite needs something
  non-stock, such as darkroom's ComfyUI custom nodes;
- **the official guides** for the rest.

The env-var facts come from each package's `dev` branch, and the package docs
stay the source of truth. Hosts are always written as `<GPU_HOST>` or
`<LAN_HOST>`. Put the real address in your local `.env`.

## Nothing to install for a look around

Every demo runs without these services. Studio's static build, Lightbox,
Safelight, Assay and Cull replay recorded output, and darkroom's `make demo`
runs against fake servers. See [What to run for which UI](/docs/setup/which-services).
